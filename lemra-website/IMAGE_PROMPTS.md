# Image prompts for the LEMRA website (ChatGPT free)

**How to use**
1. Paste a prompt into ChatGPT and download the image.
2. Rename the file exactly as shown (for example `sliding-doors.jpg`).
3. Send the images back and they'll be swapped into the site.

The free plan only allows a few images a day, so start with the **Priority** list.

Every prompt already includes the shared style, so each one works on its own.

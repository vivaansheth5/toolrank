# LEMRA Aluminium & Glass – Landing Page

A single-file, dependency-free landing page for LEMRA Aluminium & Glass (LEMRA Construction Pvt. Ltd.).
It is separate from the ToolRank Next.js app.

- **Preview:** open `index.html` in any browser.
- **Deploy:** upload `index.html` together with the `images/` folder to any static host (Netlify Drop, GitHub Pages, Vercel, Hostinger, cPanel…).
- **Contact form:** no backend needed. It opens WhatsApp (+91 78368 69818) or the visitor's email app
  (kaifkhantyagi@gmail.com) with the enquiry pre-filled.

To change phone numbers, email or address, search `index.html` for `7836869818`, `9810405078`,
`kaifkhantyagi@gmail.com` and `Masuri`.

Images in `images/` are AI-generated photos (made with ChatGPT from `IMAGE_PROMPTS.md`), resized for the web.
To use real project photos instead, add them to `images/` and update the matching `src` in `index.html`.
